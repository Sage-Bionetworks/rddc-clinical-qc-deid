# rddc-clinical-qc-deid

Quality checks and identifier screening for clinical data in the Rare Disease Data
Commons (RDDC). Checks report findings and leave the source data unchanged.

FHIR R4 support is in development. OMOP CDM 5.4 support is planned.

Workflows will run on Nextflow, with separate containers and releases for each standard.
Development instructions will accompany each implementation.
